## How this report is made

A GitHub Actions workflow runs every week:

```bash
domainhack --tld <every checkable TLD> check --file words.txt --parallel 16 --confirm-dns --output results.jsonl
```

Word lists: `data/wordlists/`. One request in flight per registry host, one second apart, RFC 7480 backoff and a per-host circuit breaker; results are cached between runs so taken names are not asked again until they could have expired. TLDs whose registries forbid automated lookups are never queried (`domainhack tlds --unsupported`).
