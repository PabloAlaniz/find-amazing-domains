    Supported TLDs¶

    domainhack checks availability against the registry itself: RDAP (RFC 9082/9083) where the registry offers it, port-43 WHOIS otherwise. No API keys, no captchas.

    Every generic TLD (com, app, dev, io...) is covered through the IANA RDAP bootstrap, a snapshot of which ships with the package. The country-code TLDs below were each verified live with a registered name and a random one; the real WHOIS replies are kept as test fixtures so a wrong "not found" pattern (which would report false "available" results) fails the build.

    Ask the tool itself, offline:

    domainhack tlds                 # summary + every country-code TLD
domainhack tlds cl es com.ar    # how these are checked
domainhack tlds --unsupported   # what cannot be checked, and why
domainhack tlds --all --json    # every TLD, machine-readable

    "Available" means not registered. Premium or reserved names may still show as available; confirm with a registrar before buying.

    Missing or wrong? Open a TLD issue or follow "Adding or fixing a TLD" in the contributing guide.
